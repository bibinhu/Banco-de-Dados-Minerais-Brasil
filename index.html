5 Guia e Disclaimer

Sobre o Projeto

O Banco de Dados de Minérios do Brasil foi desenvolvido como parte de um trabalho acadêmico da disciplina Auditoria Social, com o objetivo de demonstrar como dados públicos podem ser organizados, relacionados e analisados para promover transparência e facilitar consultas sobre a atividade mineral no Brasil.

A plataforma consolida informações provenientes de bases oficiais da Agência Nacional de Mineração (ANM), estruturando os dados em um modelo relacional que permite visualizar as relações entre minérios, mineradoras e processos minerários.

Finalidade

Este projeto possui caráter exclusivamente acadêmico e educacional.

Seu objetivo é demonstrar conceitos relacionados à:

  • Auditoria Social;
  • Transparência Pública;
  • Dados Abertos Governamentais;
  • Bancos de Dados Relacionais;
  • Visualização e organização de informações públicas.

O sistema não possui finalidade comercial, não substitui os sistemas oficiais dos órgãos públicos e não realiza qualquer alteração nos dados disponibilizados pelas instituições responsáveis.

Fontes dos Dados

Este projeto utiliza exclusivamente dados públicos oficiais, disponibilizados pelo Governo Federal por meio da política de Dados Abertos, sem qualquer modificação em seu conteúdo original.

Portal de Dados Abertos (Ministério da Fazenda)

Usamos dados do Portal de Dados Abertos para conseguir informações referentes a cada CNPJ.

Link: https://dados.gov.br/dados/conjuntos-dados/cadastro-nacional-da-pessoa-juridica---cnpj

Agência Nacional de Mineração (ANM)

Cruzamos esses dados com a base de dados abertos da ANM:

  • Anuário Mineral Brasileiro (AMB): Produção mineral e destinação
  • Cadastro Mineiro: Processos e títulos minerários
  • SIGMINE: Localização geográfica das áreas minerárias

Link: https://www.gov.br/anm/pt-br/acesso-a-informacao/dados-abertos/bases-de-dados

Disclaimer

Este projeto foi desenvolvido exclusivamente para fins acadêmicos, como parte da disciplina Auditoria Social.

Seu objetivo é demonstrar a utilização de dados públicos governamentais na construção de um banco de dados relacional, permitindo a organização, consulta e análise de informações sobre a atividade mineral no Brasil.

O projeto não possui vínculo institucional com a Agência Nacional de Mineração (ANM), a Receita Federal do Brasil (RFB), o Ministério de Minas e Energia ou qualquer outro órgão governamental.

As informações apresentadas refletem os dados disponibilizados pelos órgãos oficiais na data da coleta. Eventuais inconsistências, divergências ou desatualizações são de responsabilidade das respectivas bases públicas, não deste projeto.
